# PartyGDK
**Набор для создания Jackbox-подобных игр на Unity.**

PartyGDK представляет собой минимальный набор для создания игр для вечеринок. В его состав входят:

- WebSocket-сервер (Node.js) *[Текущая версия: **0.10.2**]*;
- ~~Сайт (контроллер) для входа в игру (Express.js) *[Текущая версия: **0.10.4**]*~~ **(устарел)**;
- Сайт (контроллер) для входа в игру (Vue) *[Текущая версия: **0.8.0**]*;
- Небольшой пакет на Unity *[Текущая версия: **0.9.5**]*.

Работа над ним началась ещё в июне 2024 года и шла с огромными перерывами.

## О пакете для Unity
Пакет для Unity представляет собой скрипты, позволяющие взаимодействовать с сервером и отправлять данные. Внутри него также находится интерпретация тестового приложения.

Пакет протестирован на версии Unity `2022.3`.

### Установка
Выберите в менеджере пакетов Unity добавление пакета с диска и укажите файл `package.json` в папке `unity`.

> [!WARNING]
>
> Для работы пакета PartyGDK требуется установить NuGet-пакеты `WebSocketSharp` и `Newtonsoft.Json`. Это можно сделать, установив [NuGetForUnity](https://github.com/GlitchEnzo/NuGetForUnity/releases).

### Настройка подключения

#### Игра
Файл настроек подключения (`connectionSettings.txt`) находится в корневой папке игры. Ниже приведён пример конфигурации:

```
Host=server.example.com
Port=443
WebSocketSuffix=/ws
Url=/createRoom
IsSecuredConnection=true
JoinUrl=example.com
```
- `Host` — адрес сервера (может отличаться от `JoinUrl`);
- `Port` — порт сервера;
- `WebSocketSuffix` — суффикс в адресе WebSockets, например `wss://server.example.com/ws/play`. Если не используется, оставьте пустым;
- `Url` — URL для создания комнаты, идущий после суффикса. Используется как в POST-запросе, так и в WebSockets.
- `IsSecuredConnection` — будут ли использоваться защищённые протоколы для WebSockets и POST-запроса (WSS и HTTPS соответственно). Убедитесь, что вы установили сертификат на сервер и включили поддержку SSL в конфигурации;
- `JoinUrl` — URL для входа в игру, отображающийся в лобби.

#### Сайт
Настройки подключения для сайта хранятся в файле конфигурации. Они изменяются аналогично настройкам подключения для игры.

> [!WARNING]
>
> Компонент `website_js`, использующий Express и jQuery, **устарел** и **будет удалён** из репозитория в ближайшее время ввиду сложности дальнейшего масштабирования. Вместо него следует собрать `website_vue` и использовать его на любом удобном веб-сервере.

#### Переменные среды
Вы можете задать хост и порт через переменные среды. Они по приоритету находятся выше, чем настройки в файле конфигурации.
- Сервер поддерживает задание переменных `HOST` и `PORT`.

## Официальный сервер
На данный момент официального сервера игры **нет**. Для того, чтобы запустить игру, вам нужно либо найти уже существующий сервер, либо создать собственный.
